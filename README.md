# Codex Changer

Нативное приложение для macOS: сохранённые аккаунты Codex, лимиты и переключение профилей.

**[Скачать последнюю версию](https://github.com/Arturstm/Codex-Changer-Releases/releases/latest)**

Для Mac с Apple Silicon (M1 и новее), macOS 13 или новее.

## Установка

Скачайте ZIP из Releases, распакуйте и переместите `CodexChanger.app` в «Программы».

Начиная с 0.15.0 новые версии доступны через **Codex Changer → Проверить обновления…** и раздел **Настройки → Обновления**. Установка требует подтверждения; аккаунты и настройки сохраняются. Старые версии без этой функции нужно обновить вручную один раз.

Приложение пока не заверено Apple (notarization). На другом Mac первая установка может быть остановлена Gatekeeper; не отключайте защиту системы целиком. Скачивайте приложение только из этого репозитория.

Не публикуйте файлы `auth.json`: они содержат данные доступа к аккаунтам.
